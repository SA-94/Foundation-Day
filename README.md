# يوم التأسيس — زراعتنا يوم بدينا

### ▶ [افتح الموقع](https://sa-94.github.io/Foundation-Day/)

موقع فعاليات يوم التأسيس السعودي لـ **فريق الكلية التطوعي**.

## المحتوى
- **عرض افتتاحي** بالفيديو مع زر تخطي.
- **صفحة الفعاليات** (`next-page.html`): عدّاد تنازلي لموعد اليوم، وروابط الأقسام.
- **أقسام الفعاليات** في مجلد `cod`:
  - المعارض الفنية
  - المسابقات الثقافية
  - مسابقة الألعاب (لعبة ذاكرة بمراحل ووقت ومحاولات)
  - العرض التراثي
  - الحدث التاريخي
  - العروض المسرحية

## هيكل الملفات
| المسار | المحتوى |
|---|---|
| `index.html` | العرض الافتتاحي |
| `next-page.html` | الصفحة الرئيسية للفعاليات |
| `cod/` | صفحات الأقسام |
| `images/` | الشعار والخريطة وصور أخرى |
| `video/` | مقاطع العرض |
| `wow/` | صور الموقع |

## التشغيل
ملفات HTML و CSS و JavaScript بلا مكتبات ولا خادم. افتح `index.html` في أي متصفح.
